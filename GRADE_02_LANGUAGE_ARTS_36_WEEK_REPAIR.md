# Grade 2 Language Arts — 36 Week Instructional Repair

This package completes the Grade 2 Language Arts instructional data layer across 36 weeks / 180 daily lessons.

Each day follows the Khaemenes Sovereign Daily Lesson Standard:
Mission → Warm-Up → Teach → Worked Example → Guided Practice → Independent Practice → Challenge → Student Creation → Check for Understanding → Mastery Evidence → Support → Extension → Reflection → Local Save.

Weekly arc:
- Monday Discover
- Tuesday Practice
- Wednesday Apply
- Thursday Create / Reason
- Friday Demonstrate

Mastery threshold: 80%.

The data object is located at:
`grades/grade-02/data/language-arts-instructional-layer-36-weeks.json`

This is content-level authoring, not merely a template rename. Each week has a distinct language-arts focus spanning reading, writing, vocabulary, and grammar/conventions.
