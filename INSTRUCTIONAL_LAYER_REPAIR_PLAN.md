# Khaemenes Elementary — Instructional Layer Repair

## Status
Pilot implementation: **Grade 1 · Week 01**

## What changed
The repository architecture and Grade 1 mastery/local-storage engine were preserved. The instructional layer for Grade 1 Week 01 was rewritten from generic template language into a substantive daily lesson model.

Each pilot day now contains:
- skill
- alignment
- objective / Today's Mission
- vocabulary
- warm-up
- teach / mini-lesson
- worked example
- guided practice
- independent practice
- challenge
- student creation
- check for understanding
- mastery evidence
- support
- extension
- student reflection
- estimated time

## Weekly progression
- Monday — Discover
- Tuesday — Practice
- Wednesday — Apply
- Thursday — Create/Reason
- Friday — Demonstrate

## Reusable standard
Future lessons should meet the Sovereign Daily Lesson Standard:

1. Today's Mission
2. Why It Matters
3. Warm-Up
4. Teach
5. Worked Example
6. Guided Practice
7. Independent Challenge
8. Student Creation
9. Check for Understanding
10. Mastery Evidence
11. Support
12. Extension
13. Student Reflection
14. Local Save

## Important
This is intentionally a **pilot**, not a claim that all 5,940 existing daily lesson blocks have been repaired. The next production step is to apply the same instructional schema subject-by-subject and week-by-week, validating each lesson for actual skill progression rather than merely changing wording.
