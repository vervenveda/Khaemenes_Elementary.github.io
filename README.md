# Khaemenes Academy First Grade — 36 Unit A+ Curriculum

Generated: 2026-08-08

Complete in-house first-grade curriculum for GitHub Pages.

## Included

- 36 units / 36 weeks
- 5 lessons per unit
- 180 daily lessons
- Professional centered printables for every unit
- 36 weekly mastery assessments
- Midyear demonstration / midterm
- Final readiness demonstration / final exam
- Teacher tools
- Local student record tracker
- 80% completion certification logic
- Standards-style internal crosswalk
- No outside fonts, scripts, images, libraries, or curriculum dependencies

## Printable Style

Clean centered worksheet pages with name/date boxes, large directions, handwriting lines, word copy pages, writing workshop pages, addition/subtraction pages, clock/time pages, inquiry pages, map/social pages, shape pages, and equal-share pages.

## Certification Rule

Certificate unlocks when weekly assessment average, midterm, final, and portfolio evidence are all at 80% or complete.
