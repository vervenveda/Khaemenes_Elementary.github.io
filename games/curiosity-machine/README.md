# Curiosity Machine 💭

**Khaemenes Elementary · Grades 1–5 · Science + Writing + Reasoning**

Curiosity Machine is a local-first inquiry app built around one developmentally appropriate question at a time.

The learning cycle is:

**Predict → Explain → Draw → Test → Observe → Revise**

## Core features

- Grades 1–5
- science topic filters
- developmentally appropriate prompt library
- prediction writing
- sentence starters
- explanation / reasoning
- drawing canvas
- safe test planner
- simple variable thinking
- observation and evidence
- before / after comparison
- revision of thinking
- local curiosity portfolio
- JSON export
- print / Save PDF
- friendly browser voices

## Science categories

- Living Things
- Earth & Space
- Matter & Materials
- Force & Motion
- Weather & Water
- Engineering

## Grade progression

### Grade 1
- oral / short written predictions
- simple cause and effect
- drawing
- counting
- noticing change

### Grade 2
- prediction + reason
- one thing changed
- careful observation
- before / after comparison

### Grade 3
- separate prediction from evidence
- simple fair tests
- measurement / counting
- revisions

### Grade 4
- variables
- repeated observations
- patterns
- data-informed explanation

### Grade 5
- controlled investigations
- competing explanations
- measurements / tables
- evidence-based justification

## Safety

The app explicitly tells children to use only safe, age-appropriate materials and to ask an adult before using:

- heat
- sharp tools
- electricity
- chemicals
- medicine
- flame
- other potentially hazardous materials

The app also supports **thought experiments** so a child can reason scientifically even when a physical test is not appropriate.
