# Junior Engineer Studio 🛠️

**Khaemenes Elementary · Grades 1–5**

Junior Engineer Studio is a sovereign, local-first engineering design workspace built around:

**Ask → Imagine → Draw → Build → Test → Improve**

## Direct inspiration from OHMIC Foundry™ Protected CAD Studio

This version was rebuilt after inspecting the actual `Ohmic_CAD_Studio.html`, not just the OHMIC gateway.

The professional CAD source describes itself as a local-first drafting environment with:

- precision tools
- visible undo / redo
- version history
- model metadata
- constraint-based layout generation
- recovery
- printing
- project storage
- portable exports

Its workspace also includes:

- a dedicated tool rail
- a central stage/canvas
- a sidebar
- crosshair / coordinate feedback
- object lists
- layer-like object management
- snap-style precision
- project history
- status information

Junior Engineer Studio translates those professional concepts into an elementary design environment rather than exposing children to the full complexity of a professional CAD system.

## Junior CAD tools

The built-in CAD-inspired sketch workspace includes:

- Select
- Line
- Rectangle
- Free Sketch
- Erase
- Object selection
- Object list
- Grid snapping
- Snap Off / 5 / 10 / 20 px
- Coordinate readout
- Undo
- Redo
- Duplicate selected object
- Delete selected object
- Width
- Height
- Area
- Width:height ratio
- Scale note
- PNG export

This lets a first- or second-grader sketch simply, while upper elementary learners can begin using measurement, ratio, geometry, and scale language.

## Grade progression

### Grade 1
Define a simple problem, sketch a solution, test whether it works, and name one improvement.

### Grade 2
Define the problem, imagine multiple solutions, sketch/model, test, compare two solutions, and use evidence.

### Grade 3
Add criteria, constraints, repeated tests, measurements, and stronger comparison evidence.

### Grade 4
Use controlled variables, scaled/dimensioned sketches, measurements, and tradeoffs.

### Grade 5
Use quantitative criteria, geometry, ratios, multiple trials, optimization, and evidence-based engineering arguments.

## Engineering evidence

Each project can contain:

- problem statement
- brainstorming
- CAD-inspired sketch
- build/material plan
- trial results
- Design A / Design B comparison
- improvement decision
- portfolio evidence

## Design principle

**Professional tools should inspire children without overwhelming them.**

Junior Engineer Studio keeps the professional ideas—precision, objects, dimensions, iteration, undo/redo, project history, and evidence—but presents them through an elementary design cycle.
