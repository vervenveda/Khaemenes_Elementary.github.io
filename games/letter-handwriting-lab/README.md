# Letter & Handwriting Garden — K–12 v5 Unified

This release combines the cleaner workbook visual direction of v4 with the broader K–12 learning architecture developed in v3.

## Unified navigation
- Worksheet Studio
- Interactive Practice
- Cursive Lab
- Listen & Write
- Portfolio Growth

## Worksheet Studio
The central printable page uses:
- Name and Date lines
- large cursive heading
- explicit stroke instructions
- model and trace examples
- traditional handwriting guidelines
- dashed midline
- independent free-writing rows
- subtle garden-growth motif
- clean black-and-white print behavior

## Activity types
- single-letter cursive
- A–F cursive group
- manuscript/printing practice
- custom word/name
- dictation
- cursive connections
- signature practice

## Practice tools
- mouse
- touch
- stylus
- pen size control
- clear / undo
- local growth samples

## K–12 progression
The level selector supports:
- Kindergarten
- Elementary 1–2
- Elementary 3–5
- Middle School 6–8
- High School 9–12

The same interface can therefore mature with the learner while preserving longitudinal handwriting evidence.

## Portfolio
Saved samples remain local and can include:
- guided practice
- cursive connections
- dictation
- worksheet-linked work

JSON export:
`handwriting-growth-portfolio.json`

## Privacy
No external libraries, trackers, accounts, cloud storage, or remote services are required.

## Printing
The app hides navigation and controls when printing so the handwriting page prints as a clean classroom worksheet.

## Suggested placement
`Khaemenes_Elementary.github.io/games/letter-handwriting-garden/index.html`

Then link the same app from Kinder Garden, Elementary, Middle School, High School, and Linguistics portals.
