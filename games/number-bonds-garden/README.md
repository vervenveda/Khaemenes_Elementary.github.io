# Number Bonds Garden 🌱

A standalone sovereign K–2 mathematics app for composing/decomposing numbers 0–10, early addition/subtraction, and handwriting numerals.

## Core progression
**See → Build → Break Apart → Recombine → Equation → Story → Write**

## Modes
- Build a Bond
- Ten-Frame Lab
- Equation Garden
- Story Bonds
- Fact Families
- Write Numbers 0–10
- Growth Portfolio

## Number handwriting
The numeral-writing section reuses the handwriting logic developed for Letter & Handwriting Garden:
- trace numerals
- copy numerals
- write independently
- mouse/touch/stylus canvas
- printable number-writing page
- save representative numeral samples

This is intentionally integrated because early number sense and numeral formation reinforce each other.

## Curriculum scope
Primary:
- Kindergarten
- Grade 1

Additional:
- Preschool readiness
- Grade 2 review/intervention

## Adaptive practice
Local mastery estimates are stored per whole number 0–10. Lower-confidence numbers are revisited more often.

This is practice adaptation, not a diagnostic score.
