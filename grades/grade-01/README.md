# Khaemenes First Grade Mastery Curriculum v1

Repository-ready Grade 01 curriculum package.

## Included

- 36 weeks / 36 units
- 5 daily lessons per week
- 180 daily lesson blocks
- 36 weekly mastery quizzes
- 80% mastery gate for weekly progression
- Multiple attempts with best score saved locally
- Midterm after Week 18
- Final after Week 36
- Certificate/report page
- Printable weekly packets
- Teacher/parent mentor toolkit
- Vanilla HTML/CSS/JS
- LocalStorage only
- No third-party libraries, fonts, images, or curriculum calls

## Upload path

This ZIP is structured to merge at the repository root:

```text
grades/grade-01/
```

Back up the existing Grade 01 folder before replacing or merging.

## Mastery flow

```text
Week 1 open
Week 2 unlocks after Week 1 quiz >= 80%
...
Midterm unlocks after Week 18 quiz >= 80%
Final unlocks after Week 36 quiz >= 80%
Certificate unlocks after:
- all 36 weekly quizzes >= 80%
- midterm >= 80%
- final >= 80%
- portfolio evidence marked complete
```

## Privacy

Scores and notes are saved only in the browser through localStorage under:

```text
khaemenes.grade01.mastery.v1
```

This package does not store passwords, passcodes, tokens, private keys, or student secrets.
