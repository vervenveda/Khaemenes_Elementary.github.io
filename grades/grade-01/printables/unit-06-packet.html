Printable Packet · Week 06

Weather, Seasons, and Data

Essential Question: How can we use words, numbers, and pictures to describe weather?

Weekly Focus

Literacy: informational text features, weather words, oral report

Math: collect data, picture graphs, compare more/less

Inquiry: weather observations and seasonal patterns

Project: Class Weather Graph

Vocabulary: weather, season, data, graph, observe, compare

Five-day evidence prompts

Monday · Launch, Listen, and Read

Objective: I can describe weather with observed evidence and explain what proves my answer.

Independent task: Record one safe, dated sky observation and distinguish it from a forecast.

Evidence to keep: Dated observation with sky symbol and caption. Ask the student to point to, say or write the evidence for the conclusion.

Student work / adult observation: _____________________________________________________

Tuesday · Skill Practice and Number Talk

Objective: I can collect weather data using tallies and explain what proves my answer.

Independent task: Sort a new set of five illustrated days, tally by type and compare category totals.

Evidence to keep: Labeled weather tally chart. Ask the student to point to, say or write the evidence for the conclusion.

Student work / adult observation: _____________________________________________________

Wednesday · Inquiry Workshop

Objective: I can compare weather and seasonal patterns and explain what proves my answer.

Independent task: Compare two short weather logs and state one difference and one limitation.

Evidence to keep: Two dated weather comparisons. Ask the student to point to, say or write the evidence for the conclusion.

Student work / adult observation: _____________________________________________________

Thursday · Create, Write, and Explain

Objective: I can create a picture graph with a one-day key and explain what proves my answer.

Independent task: Turn a new six-day weather tally into a graph with title, labels and a key.

Evidence to keep: Class Weather Graph with readable legend. Ask the student to point to, say or write the evidence for the conclusion.

Student work / adult observation: _____________________________________________________

Friday · Review, Reflect, and Mastery Check

Objective: I can interpret fresh weather data and make safe decisions and explain what proves my answer.

Independent task: Independently describe the difference between categories and identify an adult-supported safety action for severe weather.

Evidence to keep: Weather graph interpretation and safety explanation. Ask the student to point to, say or write the evidence for the conclusion.
