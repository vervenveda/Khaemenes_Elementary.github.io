Week 06 Civic Reasoning Studio

Inquiry: How do classmates make fair shared-space decisions?

Evidence task: Original scenario: Two fictional classes both want the library room at noon. Suggest a schedule, name whose voices to hear, and explain a fair tradeoff.

Review: State one supported idea, identify one voice missing from the evidence, and revise. This activity is optional instructional evidence; the canonical Social Studies assessment is unchanged.

Week 06 · Five-day inquiry and evidence lab

Monday · Source reading: Read the fictional library conflict: Class A and Class B both request the same room at noon. Identify the shared resource, two needs and who should be consulted.

Tuesday · Guided comparison: Compare a schedule giving A Monday/Wednesday and B Tuesday/Thursday with a schedule giving one class every day. Explain which evidence is missing about class size and access.

Wednesday · Evidence investigation: Draw a five-day library-use timetable with a clearly labeled shared period. Offer another equivalent option for learners unable to use the room at noon.

Thursday · Challenge and critique: Evaluate the claim that 'first to ask always wins'; use a fairness rule and explain how the result might change when students have different access needs.

Friday · Civic defense and revision: Present a revised timetable, two perspectives, a supported fairness claim and one unresolved question. Demonstrate kind discussion without requiring agreement.

Evidence standard: Identify which sources are fictional, distinguish observations from assumptions, represent more than one perspective, correct one unsupported claim, and preserve an optional written, drawn or oral explanation. Official weekly mastery, assessments, student records and teacher-review boundaries are unchanged.
