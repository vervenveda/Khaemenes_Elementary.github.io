# Upload Map — Grade 04

This ZIP contains a top-level folder named:

`grade-04/`

For the Khaemenes Elementary repository, upload the contents to:

`grades/grade-04/`

The folder should contain:

- index.html
- README.md
- LICENSE.md
- UPLOAD_MAP.md
- VALIDATION.md
- assets/
- data/
- subjects/
- weekly-plans/
- printables/
- assessments/
- teacher-tools/
- records/
- docs/

Important: Do not upload these files into the repository root unless you intentionally want Grade 04 to replace the main elementary homepage.

Dependency rule: no CDN fonts, outside scripts, outside curriculum embeds, outside worksheet images, or required external assets.
