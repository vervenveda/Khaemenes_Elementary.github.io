# Workflow · Development and Conversation Journal

Record dated **audits, tests, repairs, upgrades, decisions and Codex updates** in this root-level folder.

- `README.md` — rules
- `INDEX.md` — dated register
- `templates/SESSION_LOG_TEMPLATE.md` — reusable log template
- `logs/YYYY/MM/YYYY-MM-DD-topic.md` — actual session entries

Use ISO dates and precise file/commit references. Separate evidence, planned fixes, completed changes and verified tests. A summarized discussion is not a verbatim transcript. Add every entry to INDEX.md. Do not include student records, secrets, tokens or private data. Preserve learner-scoped records, historical assessment attempts, mastery thresholds and evaluator authority. Logs do not themselves deploy code or verify fixes.
